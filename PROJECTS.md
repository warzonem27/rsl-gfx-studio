# RSL projects in this folder

The code lives in `studio/`, `site/` and `tools/`; it is the only part tracked in git.
All design work sits in `projects/`, which is ignored by git: it's too big for GitHub and private.

| Folder in `projects/` | What it is |
|---|---|
| `RSL GFX Studio (references)` | Inputs for the studio app: the Azzuu reference notes (3 PDFs), `RSL_GFX_Guidelines_26_FINAL_NEW.pdf` (brand guidelines), `4جولات.psd` (Arabic matchweek layout). |
| `SPL Infographics from PSD` | Infographic PSDs: 01 active monitoring (+ two test versions), 02 governance, 03 three rules, 04 program stages, 05 evaluation. |
| `SPL Fantasy TVC` | Fantasy campaign: promo treatment (PDF/AI), RSL treatment M15, storyboard PPTX, Higgsfield frames PDF, influencer script XLSX, "Low Ana Almodarreb" frames. |
| `Motion Graphic Frames (FRA & PACE)` | FRA (financial regulations) and PACE explainer videos: scene frames (PNG/SVG + SCENE_GUIDE.md), PACE_frames with `add_live_arabic_text.jsx` and on-screen text, briefs/scripts (DOCX), ElevenLabs VO takes, timelines and renders. |
| `Video Editing Guidelines` | `Video editing guidlines-1.ai`: RSL video editing guideline document. |

## Brand rules (apply to all of the above)
- Fonts: Lama Sans (text) and Expanded Numbers (figures).
- English and Arabic versions; Arabic mirrored right-to-left; use الجولة, not MW.
- Follow `RSL_GFX_Guidelines_26_FINAL_NEW.pdf`.
